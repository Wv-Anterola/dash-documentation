## What this year was about

Dash had an LLM chatbot before 2025. What it did not have was a way for the
model to do anything. The registry built this year is the difference: a set of
tools the agent dispatches to, each one a small class with a schema, so adding a
capability means adding a file rather than editing a prompt.

Once that existed, the interesting question became what to put in it. Some of
the answers were obvious in hindsight and had simply been impossible before, like
letting the agent see the documents on the canvas in front of you. One of them
was stranger: the agent was given search over Dash's own source, so it could
answer questions about the system it was running inside, and then a path to
generate a new tool and have it built into the running application.

Alongside that, the group kept adding document types. Symbolic mathematics moved
into a web worker so evaluating an equation would not freeze the interface, and
3D arrived properly for the first time, both as a viewer and as a sketching
canvas.
