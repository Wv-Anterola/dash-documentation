# Features

Tutorial pages for Dash features, written by the students who built them.
This section covers linking, annotation and markup, ink, presentation trails,
search, animation, scripting, collaboration, and generative AI.

{: .caveat }
> This is not a complete list of what Dash does, and it has not been for some
> time. Pages here get written when someone has time rather than when a feature
> ships, so several things in the current build have no page: the agent and its
> tools, video generation, policy analysis documents, 3D sketching, the link
> graph collection view, and the desktop build with local models.
>
> Those are described, with their implementation status and who built them, on
> the [Projects]({{ '/projects/' | relative_url }}) and
> [Cohorts]({{ '/cohorts/' | relative_url }}) pages.
>
> If you work on Dash and want to close one of these gaps,
> [Contributing]({{ '/contributing/' | relative_url }}) explains how.
