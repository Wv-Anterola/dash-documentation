## Outcome

A collection of titled sources, precise annotations, claim-to-evidence links,
synthesis notes, and a presentation trail in which every conclusion can be
followed back to source material.

## 1. Establish the corpus

Create one top-level collection for the research question. Import PDFs, web
sources, images, interview audio, or policy testimony. Keep the original source
files outside Dash when archival integrity matters.

For every source, record at least:

- Descriptive title
- Author or organization
- Publication or capture date
- Source URL or citation
- License or access note when relevant
- Review status

Do this before creating many links. Untitled or ambiguously titled sources
make backlinks, search results, trails, and agent citations difficult to
review.

## 2. Read and annotate precisely

Annotate passages, figures, timestamps, or image regions rather than writing
all observations in a detached notes file.

Use a consistent annotation vocabulary:

- Claim
- Method
- Evidence
- Limitation
- Definition
- Open question

Annotations can be spatially arranged in a freeform view and inspected as
records in schema view.

## 3. Link claims to evidence

Create synthesis notes for your own claims. Link each claim to the exact source
region that supports, complicates, or contradicts it. Put the relationship in
the link description.

A useful test is whether a collaborator can follow the link and understand why
it exists without asking you.

## 4. Change perspective

Use different views for different questions:

- Freeform for emerging clusters.
- Schema for metadata cleanup and review status.
- Graph for connection structure and isolated sources.
- Stacking for grouping by theme or evidence role.

Changing view does not convert the collection. Return to schema periodically
to catch missing metadata.

## 5. Use the assistant cautiously

Ask the retrieval assistant to compare, summarize, or find disagreements only
after the corpus is titled and scoped.

Require citations. Open every citation used in an important conclusion. If the
assistant fails to cite a known source, search directly before concluding that
the source is irrelevant.

For policy workflows, use testimony/checker documents to retain source-level
citations. Treat the checker output as a review aid.

## 6. Present without detaching from evidence

Create a trail through the synthesis notes and strongest evidence. Pin with
view when a passage, region, or chart selection must be visible. Add a branch
for methodological detail or counterevidence.

Before presenting:

- Follow every evidence link.
- Test the branch and return path.
- Check access permissions for collaborators.
- Label generated or AI-summarized material.
- Export or archive the source list.

## Definition of done

- Every source is titled and attributed.
- Every major claim has a navigable evidence link.
- Contradictory evidence is not hidden in an unused view.
- AI-derived statements have checked citations.
- The trail can be followed by someone who did not build the workspace.
