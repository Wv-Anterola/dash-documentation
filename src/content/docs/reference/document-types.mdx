## Sentinel

`NONE` represents the absence of a document type. `LOADING` represents a
loading state. Neither is a user capability.

## Integration note

A usable document type requires more than this enum: prototype, factory,
renderer registration, creation or import path, persistence, undo, tests, and
documentation. See [Add a document type](/development/add-document-type/).
