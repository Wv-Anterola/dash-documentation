## Verification method

Claims were checked against the type enum, `CollectionView.renderSubView`,
`CollectionView.setupViewTypes`, the `Agent` constructor, the
`DocumentContentsView.Init` component registry, and source paths recorded in the
capability registry.

Project integration status remains evidence-backed prose maintained in
`src/data/projects.ts`. Capability coverage is enforced automatically, but a
future documentation update must still re-check project status against the
new source commit.

## Updating the snapshot

1. Fetch the intended Dash-Web remote.
2. Record the exact commit hash.
3. Re-run registry inventory checks.
4. Inspect added and removed user entry points.
5. Update capability availability and source paths.
6. Update project statuses only with direct evidence.
7. Run documentation coverage, type, build, and link checks.
8. Record the change in release history.
