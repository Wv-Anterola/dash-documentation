This is a map, not a showcase. The full write-up for each project lives on its
[cohort page](/research/cohorts/), and the ideas behind the work are in
[concepts](/concepts/). The concepts column below is the fastest way in if you
care about a topic rather than a year.

## How to read the status column

A project counts as integrated only if it can be pointed at in the current
`master` branch of Dash-Web: a document type registered in `Documents.ts`, an
entry in `CollectionViewType`, a tool constructed in the agent registry, or
code one of those calls.

A merged branch does not qualify on its own, and neither does a demo recording,
a screenshot, or a finished report. Several projects below have all three and
are still not in the application. Each write-up records what was checked.

## Where the work went

Counted by system area, which is a rough map of what the group has spent seven
years on.

<table class="ref-table">
  <thead>
    <tr>

    </tr>
  </thead>
  <tbody>
    {areas().map((a) => {
      const inArea = projects.filter((p) => p.area === a);
      const integ = inArea.filter((p) => p.status === 'integrated').length;
      return (
        <tr>
          <th scope="row">{a}</th>

    })}

The document model and the agent system dominate, for different reasons.
Document types are the cheapest thing to add, so that is what a one-semester
project often becomes. The agent system is recent and concentrated: nearly all
of it arrived in 2025 and 2026, on top of the tool registry.

Commit counts cover the whole repository including merges, so treat them as a
rough measure of activity. The 2019 to 2020 figure is not a mistake: more than
half of every commit ever made to Dash-Web was made in those two years.
