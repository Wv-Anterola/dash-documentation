## About this record

Dash stopped assigning numbered releases after 0.8 in May 2022. Development of
the document system, generative tools, agent architecture, and desktop runtime
continued without a formal product-version sequence.

Changes from 2023 onward are therefore organized by cohort rather than assigned
retrospective version numbers. Cohort and project records distinguish work in
the canonical application from implemented, prototype, and archived branches.

## Documentation evidence pass, July 2026

The product manual and project archive now share one evidence model:

- all 42 recovered projects map to a real or explicitly representative visual;
- every project has a plain-language, four-stage interaction workflow;
- all 28 integrated projects map back into canonical product capabilities;
- 12 authentic interaction frames replace the final workflow placeholders;
- every local and origin branch tip is inventoried in the [branch
  audit](/reference/branch-audit/);
- 8,832 unique source versions—4,154,651 unique lines—were read and hashed
  across 149 refs, with every branch delta kept searchable.

This is a documentation release, not a new Dash application version. Branch
features still retain their implemented, prototype, archived, or unclear
labels until the relevant code is present and reachable in the current application.

## Since the last numbered release

The changes since 0.8 that most affect how Dash is used:

**A desktop application, March 2026.** Electron builds for macOS and Windows,
with an agent service that talks to a local Ollama instance, so the AI features
can run against a model on your own machine instead of a remote API. Ollama is
installed separately rather than shipped in the build.

**An agent that acts, from 2025.** The chatbot answers questions about your
documents. The agent, built on a tool registry, filters, sorts, tags, links,
creates documents, and drives the interface. Twenty-two tools are registered at
startup, and it can generate another.

**New document types**: 3D model viewing and sketching, video generation, policy
analysis, life-coach workspaces, scrapbooks, journals, tasks, and equations with
a symbolic solver.

**New collection views**: calendar in 2023, link graph in 2026.

**Generative AI beyond text nodes**: image generation with style and structure
references, chart generation from CSVs, presentation transitions described in
words, selection-aware text reformatting.

## Numbered releases, 2020 to 2022

The original release notes, unchanged apart from a repaired link.

### 0.8, May 2022

Sharing and dashboard updates so that new users arrive at a homepage. Updated
video mode for trails that tracks movement around the canvas.

### 0.6, January 2022

Performance optimisation involving caching, and rendering low-resolution images
of websites instead of rendering the entire website.

### 0.5, October 2021

Stable release including significant bug fixes.

### 0.4, September 2021

UI overhaul and a completely updated novice mode.

### 0.3, May 2021

Document toolbar redesign; schema view updates.

### 0.2, December 2020

The version used in the seminar taught in Fall 2020. Extended functionality for
[presentation trails](/guides/features/trails/); sharing and
access controls.

### 0.1, January 2020

The earliest version of Dash.

## Feature requests

The Google Form that used to collect feature requests no longer resolves, so
this page no longer links to it. Use the **Issue reporter** in the Dash top bar
instead: it is documented in the [interface control
atlas](/reference/interface-controls/?control=Issue%20reporter) and reaches the
group directly.

:::note[Historical roadmap status]
A 2022 roadmap named maps, progressive and branching trails, mathematical
notetaking, smart transcription, and schema autofill. Maps, branching trails,
symbolic mathematics, and dictation now have implementation records. Items
without current implementation evidence remain in the research archive rather
than being advertised as available capabilities.
:::
