Generative AI moved from a novelty attached to text nodes into several parts of
the system at once: drawing, data visualisation, presentation transitions, and
a first pass at an assistant that could act on documents.

## What this year was about

In 2023, generative AI in Dash meant one thing: you could ask GPT to write into
a text node. In 2024 it stopped being one thing. Ink got a path from a rough
sketch to a generated image. Charts got generated defaults. Presentation
transitions got a model that could be described in words instead of tuned by
hand. An early assistant learned to create documents rather than only describe
them.

Not all of it stuck. The search and curation work from this year sits on four
unmerged branches, and the assistant's document-creation tool was superseded by
the registry that arrived the following year. That is worth saying plainly,
because the branches are still there and it would be easy to read their
existence as evidence that the features shipped.

The non-AI work from this year is some of the most durable. Interactive chart
filtering and the spring-physics animation model are both still in `master`.
