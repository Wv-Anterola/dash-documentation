The founding period. The repository's first commit is December 2018, and the
two years after it established nearly everything the system still rests on.

## What these years were about

The core document model, collections, links, view system, and direct-manipulation
workspace were established in 2019 and 2020. Later work continues to build on
those contracts.

Several decisions from this period remain part of the current runtime. A
single document abstraction with typed fields and prototype inheritance, so a
PDF and a collection and a link are all the same kind of thing. Collections
that are themselves documents, with the display style as a property rather than
a separate object. Links that anchor to a region, a selection, or a timestamp
instead of to a file.

The concrete evidence of continuity is that current document types still use
the same registry and factory boundaries established during this period. The
graph view is another value in the `CollectionViewType` enum first populated
then.
