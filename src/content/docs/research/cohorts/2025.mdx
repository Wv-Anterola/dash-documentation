The year the chatbot turned into an agent with a real tool registry. Work split
between extending what the agent could touch and adding document types around
it.

## What this year was about

Dash had an LLM chatbot before 2025. What it did not have was a way for the
model to do anything. The registry built this year is the difference: a set of
tools the agent dispatches to, each a small class with a schema, so adding a
capability means adding a file rather than editing a prompt.

Once that existed, the design question became which capabilities belonged in
the registry. One addition exposed the documents on the active canvas as agent
context. Another gave the agent search access to Dash's source so it could answer
questions about the system it was running inside, and then a path to generate a
new tool and have it compiled into the running application.

Alongside that, the group kept adding document types. Symbolic mathematics
moved into a web worker so evaluating an equation would not freeze the
interface, and 3D arrived properly for the first time, both as a viewer and as
a sketching canvas.
