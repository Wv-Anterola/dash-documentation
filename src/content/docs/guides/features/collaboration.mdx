Every document carries an access control level, or ACL, for each individual,
group, and guest it is shared with. The ACL decides how much of the document
that party can change.

## Access levels

The levels are cumulative: each one can do everything the level below it can,
plus one more thing.

| Level | Can do | Beyond the level below |
| :---- | :----- | :--------------------- |
| **Admin** | Everything below, plus change the ACLs themselves | Controls who else has access |
| **Edit** | Move, resize, add content, and delete or minimise any document | Can delete other people's content |
| **Augment** | Move, resize, add content, and delete their own content | Can add, but not remove others' work |
| **View** | Read the document | Cannot edit, delete, or move anything |
| **Not shared** | Nothing | Cannot see the document or dashboard at all |

Augment is the level worth understanding, because it is the one with no
equivalent in most tools: a collaborator can add to a shared canvas and remove
their own additions, without being able to delete anyone else's.

## Guests

Guests can never change a shared document. Edits made from a guest account are
not written back to the original.

Setting the guest permission to View rather than Not shared makes a document
readable by anyone who has not been given explicit access. To let a guest in,
send them the guest URL from the document's Share menu. Guests can also reach a
document by its ID.

## Nested documents and layout

:::note[Developer mode]
Both settings below appear only in developer mode.
:::

**Upgrade nested.** When a parent document is shared at a level more
restrictive than its children, the children take on the stricter permission
automatically. Going the other way is deliberate rather than automatic: for
children to inherit a *less* restrictive parent permission, you have to tick
"Upgrade nested".

**Layout.** Layout permissions govern moving and resizing. A document starts
with the layout permissions of whatever it is nested inside, until you set them
explicitly.
