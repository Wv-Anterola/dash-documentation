This section explains how to operate Dash's cross-cutting features. A feature
can work across many document types: a link may connect a PDF region to a video
interval, a filter may shape a collection in any view, and a script may read or
change the same fields shown in the properties panel.

![The current Dash Tools panel showing document creators for notes, flashcards, mathematics, images, HTML, web pages, audio, maps, trip planning, chat, data visualization, scrapbooks, journals, 3D models, tasks, and more.](/assets/images/current/dash-tools-panel.webp)

The current Tools panel is the quickest visual inventory of user-creatable
documents. The catalog below goes further by connecting those visible entry
points to workflows, architecture, and the projects that introduced them.

## Availability labels

The capability catalog separates **Core**, **Advanced**, **Prototype**, and
**Environment-dependent** features. That status is more precise than the age of
a guide. An older workflow may still be central, while a newer project may
exist only on a branch or depend on credentials and local services.

When a guide and the running client disagree, record the application build, the
route or control you tested, and the observed result. The
[documentation maintenance guide](/contributing/documentation/) explains how
to update the evidence instead of silently rewriting history.
