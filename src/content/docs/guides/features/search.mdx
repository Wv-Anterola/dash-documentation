The search flyout finds documents in the current dashboard by their metadata.
Each result shows the document's title, type, and the fields that matched.

## Using it

- Click the search icon, or press Ctrl+F, to open and close the flyout.
- Type a query to match documents whose metadata contains it.
- Use the dropdown to restrict results to one document type.
- Hover a result to see the document's full title.
- Click a result to select it and zoom to it on the canvas.

## What it does not match

Search reads metadata: titles, types, fields, tags. It does not read the text
inside a PDF, a web page, or a rich text document.

That boundary is worth knowing, because it is not how most people expect search
to behave, and it is the reason a document you know exists can be hard to find
by the phrase you remember from inside it.

Two things partly close the gap. Within a single PDF, the document's own search
control finds text on the page; see [PDFs](/guides/documents/pdf/). And the
chatbot retrieves over chunked document contents, so asking it is closer to
full-text search than the flyout is; see
[agents and tools](/concepts/agents/).
