![Screenshot: a Dash collection displayed as a schema table, with documents as rows and fields as columns.](/assets/images/environment/views/schema_view.png)

A table over a collection. Each document is a row; each column shows the value
stored under one key for that document. Nested collections expand in place.

Title, type, author, date last modified, and text are shown by default, and you
can add columns for any other key.

## What it suits

- Working with documents through their fields rather than their contents
- Sorting and comparing a set of documents on one value
- Reviewing search results in a structure you can scan
- Treating a collection as a spreadsheet

## Adding and editing columns

A column title is a key, and each cell under it is that document's value for
that key.

Click **+** in the top left to add one. You can add a column for a key the
documents already carry, or invent a new key. The difference matters: adding a
column for an existing key is a viewing operation, while adding one for a new
key writes new fields onto the documents.

Columns can hold strings, numbers, checkboxes, or documents.

To change a column, click the small circular button beside its title. The
dropdown there lets you change, filter, or delete it.

To change a cell, click it and type. String values need quotation marks.

To sort, use the arrows beside a column title.

![Screen recording: adding, sorting, and editing columns in a Dash schema view.](/assets/gifs/views/schema_columns.gif)

## Previewing a document

The leftmost column has a "show preview" toggle, which opens a live preview of
the selected row's document in a side tab. It is the fastest way to work through
a table without losing the table.
