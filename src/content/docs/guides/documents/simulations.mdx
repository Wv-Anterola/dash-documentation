:::danger[Removed feature]
Physics simulation documents are not part of the current Dash client. They were
built by Brynn Chernosky in 2023 and later removed. `DocumentTypes.ts`,
`Documents.ts`, and the renderer registry at the current snapshot contain no
simulation document type.

The controls below are a historical record. They are not instructions for the
deployed application.
:::

![A physics simulation document in Dash, showing a ramp-and-block setup with editable initial values.](/assets/images/environment/simulation_doc.png)

## What the project built

The project put introductory mechanics simulations inside the same workspace as
notes, readings, and links. Its aim was to avoid the usual choice between a
simple, fixed educational simulator and a programmable tool with a steep
learning curve.

It supported seven setups:

- projectile motion;
- inclined planes;
- pendulums;
- springs;
- pulleys;
- a weight suspended from two rods;
- circular motion.

The simulation document presented parameters at the left and mode and
simulation-type selectors at the upper right.

## Three learning modes

**Freeform mode** let a student choose parameters and run a physically computed
animation. It was intended for exploration and for checking how a system
responds when one input changes.

**Tutorial mode** led the student through the reasoning for a particular
mechanics problem step by step.

**Review mode** asked questions and drove the animation from the student's
answers. That made an incorrect answer visible as behavior rather than only a
score.

The modes were separate interfaces over the same simulation platform, not
three unrelated document types.

## Historical access and operation

In the 2023 client, typing a colon on a canvas opened the creation menu. Under
**Create Document**, **Simulation** created a default simulation. A user then
selected the simulation and learning mode from dropdowns and changed the
initial values in the parameter panel.

These entry points no longer exist. Do not add them to onboarding material or
describe simulation as an available capability.

## Why it matters to Dash's history

The work is a good example of the difference between an implemented project and
a current feature. It produced a working document, a substantial public report,
and this guide. The implementation is no longer in the current application, so
the capability catalog records it as archived rather than usable.

The report describes the educational motivation, related systems, interface,
seven simulation types, and three modes in detail:

- [Physics Simulations in the Dash Hypermedia System](https://cs.brown.edu/media/filer_public/2c/20/2c208c8e-0560-49d3-b43c-6e5136004aab/chernoskybrynn.pdf)
- [2023 project record](/research/cohorts/2023/#physics-simulation-documents)
- [Publications and project reports](/research/publications/#physics-simulations-in-the-dash-hypermedia-system)

If simulation work returns, it should receive a new project record and a new
source-backed guide. This archived page should continue to describe the 2023
implementation rather than being silently repurposed.
