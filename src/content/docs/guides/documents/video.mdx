![Screenshot: a video document open on a Dash canvas with playback controls.](/assets/images/environment/video_doc.png)

Video documents play imported clips while keeping playback state, fields,
links, and annotations in the Dash document model.

## Create one

Import a supported video through the Imports panel or drag it onto a canvas.
The media source remains distinct from the fields that store layout,
annotations, links, and current playback state.

## Playback and timeline

- Play, pause, scrub, and toggle fullscreen with the video controls.
- Toggle the timeline with the eye control.
- Place labels, documents, and temporal regions on the timeline.
- Add ink or spatial annotations over the rendered frame.

![Screen recording: scrubbing a video document along its timeline.](/assets/gifs/video/timelineview.gif)

Video uses the same temporal model as [audio](/guides/documents/audio/), but the
current video surface does not provide audio-style trimming.

## Choose the right anchor

A spatial anchor identifies a visible region of the frame. A temporal anchor
identifies a point or interval in playback. Use the one that matches the claim:
“this object” and “this thirty-second explanation” are different evidence.

Following a temporal link seeks to or plays the linked passage. Give the link a
description so the destination explains why the passage matters.

### Review workflow

1. Place the recording and review notes in one collection.
2. Scrub to the relevant passage.
3. Create a point or interval anchor.
4. Link it to a note, claim, or task.
5. Describe the relationship.
6. Follow the link once and confirm the expected passage plays.

## Format and access limits

Dash uses the browser media element, so codec support depends on the browser
and operating system. A recognized extension does not guarantee that its audio
and video codecs can be decoded.

Remote sources need compatible response headers. If a video works for the
importer but not a collaborator, check the source URL, authentication, upload
availability, content type, and codec before checking the link.

Replacing the media behind an existing document can invalidate time anchors
when duration or editing changes. Import and link a new version when auditability
matters.

## Imported versus generated video

This page covers playback of existing media. `DocumentType.VIDGEN` is a
separate scene-based generator added in 2026. See the
[video-generator project](/research/cohorts/2026/#video-generator) and
[AI capability guide](/capabilities/ai-automation/#generative-media).

## Troubleshooting

| Symptom | Check |
| :--- | :--- |
| Blank or unsupported player | Codec, content type, URL, and browser media support |
| Timeline has the wrong duration | Wait for media metadata to load; check whether the source changed |
| Link opens the video but not the interval | Confirm the endpoint is a temporal anchor rather than the whole document |
| Ink or region drifts | Rendering dimensions or source aspect ratio changed |
| Collaborator cannot play it | Upload persistence or external-host permission |

The current renderer is `VideoBox.tsx`. Timeline and temporal anchors share the
media annotation infrastructure described in
[temporal media](/guides/documents/temporal-media/) and
[links architecture](/architecture/links-trails/).
