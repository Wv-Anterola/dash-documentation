Web pages embedded directly in Dash, rather than links out to a browser.

## Creating one

Drag the lock icon beside a page's URL from your browser onto the tab running
Dash.

Alternatively, create an empty web page document from the colon menu. It opens a
Bing search, and you can type a URL into the horizontal toolbar.

![Screen recording: dragging a web page into Dash to embed it.](/assets/gifs/webpage/dash-website-embed.gif)

## What you can do

- Embed marquee selections, annotations, and ink on the overlay.
- Highlight and annotate text with the same annotation sidebar used for PDFs and
  text documents.
- Pan and scroll the page.
- Follow the page's own hyperlinks by clicking them; the target opens in the
  same document frame.

Because a highlight is a link anchor, you can link from a passage on an embedded
page to a note elsewhere on the canvas, and the link survives the page being
closed. See [links and anchors](/concepts/links/).

## Where embedding fails

Embedding works well for Wikipedia and similar pages. JavaScript-heavy sites
often break: the page may render but its internal links will not follow,
because of browser permission restrictions Dash cannot work around.

Some sites cannot be dragged in at all, for the same security reasons.

**Web clippings** are the fallback. Select the part of the page you want and
drag that into Dash instead. A clipping behaves like any other document, so you
keep the annotation and linking behaviour even where full embedding is blocked.
