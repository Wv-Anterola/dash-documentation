A webpage document places a live or captured web surface inside Dash so it can
sit beside notes, carry annotations, and participate in links and collections.
It does not make the remote site part of Dash's storage by default.

## Create one

Drag the site icon beside a browser URL onto the Dash tab, then drop it on a
canvas. You can also create an empty webpage document from the colon menu and
enter a URL in its toolbar.

![Screen recording: dragging a web page into Dash to embed it.](/assets/gifs/webpage/dash-website-embed.gif)

## Read and annotate

- Scroll and interact with the embedded page when the site permits it.
- Use the in-document search control on searchable embedded content.
- Highlight or annotate selectable text.
- Add marquee regions, ink, or documents on the overlay.
- Follow links inside the frame when site and browser policy allow it.

A highlight or region can be a link anchor. The link record survives after the
page is closed, but its target can drift if the live site changes.

## Browser boundaries

Sites can refuse embedding with `X-Frame-Options` or Content Security Policy.
Others render but block authentication, navigation, or cross-origin
inspection. Dash cannot override those browser protections.

A blank frame is not necessarily a Dash renderer bug. Test the source in a
normal browser, inspect the frame or CSP error, and use a clipping or external
link when the publisher forbids embedding.

## Live page or clipping?

Web clippings preserve selected material as a Dash document when a full page
cannot or should not remain live.

| Need | Prefer |
| :--- | :--- |
| Follow a site as it changes | Live webpage |
| Cite what was visible at a specific time | Clipping or exported capture |
| Interact with a permitted web app | Live webpage |
| Annotate a site that blocks framing | Clipping |
| Preserve searchable research material | Captured text plus source URL |

A clipping becomes useful evidence only when it includes a source URL, capture
date, and enough surrounding context. Pixels without provenance can preserve
appearance while losing meaning.

## Search boundaries

The webpage view has its own search surface, but global Dash search does not
crawl arbitrary live DOM as a general index. Global search may find the Dash
document from its title, URL, or stored text fields. The agent's semantic
retrieval is another path again.

## Troubleshooting

| Symptom | Check |
| :--- | :--- |
| Frame is blank or refuses connection | Site framing policy; use a clipping or open externally |
| Page loads but clicks fail | Content activation, locked position, frame policy, and site scripts |
| Annotation no longer aligns | Remote layout changed; preserve a capture for durable anchors |
| Global search misses visible text | Live DOM is outside the general field index |
| Collaborator gets a login screen | Remote site has its own session and permissions |
| Browser reports mixed content | HTTPS Dash is trying to embed an HTTP source |
