Images brought in from outside Dash.

## Creating one

Drag an image in from the web or from your desktop.

## What you can do

- Embed marquee selections, annotations, and ink on top of the image. The
  overlay behaves like a collection, so anything you place there is a document
  in its own right.
- **Make it a background.** "Make Background" in the right-click menu locks the
  image into the canvas: it can no longer be selected, and a red lock icon
  appears at its top right. Clicking that icon turns it back into an ordinary
  image.
- **Rotate** it 90 degrees clockwise from the right-click menu.
- **Zoom** with the scroll wheel.

## The image editor

The image editor fills a region you mark, guided by a prompt.

1. Mark the parts of the image you want replaced.
2. Describe what should go there in the prompt box.
3. Click "Get edits". Two generated versions appear alongside the original.

![Screenshot: the Dash image editor showing two generated variants beside the original image.](/assets/images/environment/image_doc2.png)

Returning to the dashboard leaves behind a collection of linked images
recording the iterations, so the versions stay connected rather than
overwriting each other.

![Screenshot: a collection of linked image versions produced by successive edits.](/assets/images/environment/image_doc3.png)
