An image document holds an image source plus Dash layout, fields, links, and an
annotation overlay. Sources can come from local import, a dragged web image,
search, or a generation service.

## Create one

Drag an image from the web or desktop onto a canvas, or use the Imports panel.
For research or publication work, record its origin and whether Dash stored a
copy or still depends on a remote URL.

## Work with the image

- Add marquee regions, annotations, documents, and ink on its overlay.
- Make a region into a link anchor when the relationship concerns one detail.
- Choose **Make Background** to lock it into the canvas; use the red lock
  control to make it selectable again.
- Rotate it 90 degrees clockwise from the context menu.
- Zoom the content with the scroll wheel while the image is active.

The overlay behaves like a collection. A note placed on the image remains a
document, not pixels burned into the file.

## Generate an edit

The image editor fills a marked region from a prompt:

1. Mark the area to replace.
2. Describe the requested result.
3. Choose **Get edits**.
4. Compare the two generated variants with the source.

![Screenshot: the Dash image editor showing two generated variants beside the original image.](/assets/images/environment/image_doc2.png)

Returning to the dashboard leaves a collection of linked versions rather than
silently overwriting the original.

![Screenshot: a collection of linked image versions produced by successive edits.](/assets/images/environment/image_doc3.png)

The editor depends on configured generation services. A visible control does
not prove the server has working Firefly or OpenAI credentials, and a successful
request does not prove the output is accurate.

## Source and generation practice

- Keep the original beside its edits.
- Title iterations so links and trails are understandable.
- Preserve prompts and reference images when reproducibility matters.
- Check provider data-handling rules before sending private material.
- Describe material that will be used outside an immediate visual workflow.
- Verify generated labels, text, people, and scientific detail manually.

## Troubleshooting

| Symptom | Check |
| :--- | :--- |
| Remote image is blank | Source still exists, response permits embedding, and URL is HTTPS |
| Wheel zoom moves the canvas | Activate the image content before scrolling |
| Background cannot be selected | Use the red lock control |
| Annotation no longer aligns | Source dimensions, rotation, or crop changed |
| **Get edits** fails | Provider credentials, server route, mask, prompt, quota, and returned content type |
| Collaborator cannot see it | Upload persistence and permission on the source |
