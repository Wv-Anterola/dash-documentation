:::note[Developer mode]
This section of the properties panel appears only in developer mode.
:::

Shows a live preview of the selected document's layout.

A document's layout is a field on the document rather than a fixed part of it,
which is why the preview updates as you change display settings in
[options](/guides/properties/options/) and why the same document can be laid out
differently in two [contexts](/guides/properties/othercontexts/).

:::caution
This section has never been documented beyond the description above. If you work
on Dash and know what the controls here do, this is one of the easiest gaps on
the site to close; see
[working on this documentation](/contributing/documentation/).
:::
