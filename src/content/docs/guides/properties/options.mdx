title: Options

---

Options holds the toggles that change how the selected document or view
displays. Which ones appear depends on what is selected and whether you are in
novice or developer mode.

Each entry below is a single control that cycles between the named settings.

## Title

Controls whether the selected document or dashboard shows its title. You can
edit the title from the text area above the document, or from the Title box in
the properties panel.

- `SHOW TITLE` puts the title at the top of the item.
- `HOVER TITLE` shows it only while you hover the document.
- `HIDE TITLE` hides it. The title itself is kept.

## Caption

A caption gives a document more context, and appears when you hover it.

- `SHOW CAPTION` lets you read and edit the caption by hovering the bottom of
  the document.
- `HIDE CAPTION` hides it. The text is kept.

## Lock

Keeps a document in place when you hover and drag it, which is what you want for
anything you have deliberately positioned.

- `LOCK` holds the document still on hover and drag. To move it, double-click to
  select it, then drag the editable text space above it.
- `UNLOCK` lets it be dragged on hover as usual.

## Fit width

Decides whether the document fills the width available to it. Most useful in
[notetaking](/guides/views/notetaking/) and
[stacking](/guides/views/stacking/) views, where documents are shown at their
natural size.

- `RESTRICT WIDTH` keeps the document's natural size and leaves space around it.
- `FIT WIDTH` stretches it across the full width of its space.

## Active

Decides what hovering a document does.

- `ACTIVE INTERACTION` lets you interact with the document's contents on hover,
  without clicking into it first.
- `INACTIVE INTERACTION` requires a click before the contents respond, so
  hovering and dragging moves the document instead.

## View all

- `VIEW ALL` fits every document on the canvas into view at once. You cannot pan
  while it is on.
- `PREVIOUS VIEW` returns to where you were.

## Grid

- `VIEW GRID` shows a grid on the freeform canvas.
- `HIDE GRID` removes it.

## Snap lines

Snap lines help you align a document against the others around it. They are
easier to read with the grid hidden.

- `SHOW SNAP LINES` displays alignment guides.
- `HIDE SNAP LINES` removes them.

## Clusters

- `HIGHLIGHT CLUSTERS` gives each document a background tint based on how close
  it is to others, so spatial groupings become visible. The colour changes as
  you move documents.
- `DISABLE CLUSTERS` removes the tint.

Clustering is a freeform-canvas idea: it reads meaning from where you put
things. The 2026 graph view takes the opposite approach and lays documents out
from their links instead; see
[collections and views](/concepts/collections/).

## Panning

- `ENABLE PANNING` lets you move around the freeform canvas.
- `DISABLE PANNING` fixes it in place.

## Highlighter mask

- `HIGHLIGHTER MASK` makes an ink stroke highlight when you hover it.
- `PLAIN INK` shows the stroke as drawn.

See [ink](/guides/features/ink/) for drawing and formatting strokes.

## Background image

- `HIDE BACKGROUND IMAGE` hides the image while keeping the document's
  dimensions.
- `SHOW BACKGROUND IMAGE` restores it.

## UI controls

:::note[Developer mode]
This option appears only in developer mode.
:::

Turns off a view's own interface controls. In notetaking view, for example,
disabling them removes the button for adding a note.

- `DISABLE UI CONTROLS` hides the view's controls.
- `ENABLE UI CONTROLS` restores them.
