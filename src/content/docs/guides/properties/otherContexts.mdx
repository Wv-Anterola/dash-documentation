---
title: Other contexts
description: The properties section listing the other places a document appears, and how to create a second context for it.
---

A document can appear in more than one place at once. Each appearance is a
context, and this section lists the others for the current selection.

Contexts are the same document, not copies. Editing it in one context changes it
in all of them.

## Creating another context

1. Start dragging the document.
2. Hold Ctrl while you drag it to where you want the second context.
3. Release the drag and the Ctrl key together.

## When this is useful

A source document can sit in the collection it belongs to and also on the canvas
where you are writing about it, without duplicating it or losing track of which
copy is current.

This works because a document's position and layout are properties of the
context rather than of the document, which is the same separation that lets a
collection change view without converting anything. See
[collections and views](/concepts/collections/).
