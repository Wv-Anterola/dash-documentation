:::note[Developer mode]
This section of the properties panel appears only in developer mode.
:::

Shows the access level every party has on the selected document: the owner,
guest users, and each individual and group it has been shared with.

Access runs at four levels, and a document can be shared with individuals, with
groups, or both.

[Collaboration](/guides/features/collaboration/) documents what each level
permits and how groups are created.

## A limitation worth knowing

These permissions govern people. They do not govern the agent, which has no
permission model of its own: a tool that can write can write to anything the
user can, and the agent decides when to call it.

That gap is described in
[what Dash currently supports](/overview/current-state/#where-the-implementation-stops),
and it is what the 2026 oversight study set out to measure; see
[agents and tools](/concepts/agents/).
