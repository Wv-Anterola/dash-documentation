This page walks through the operations you need in the first hour: getting
content onto a canvas, selecting and arranging it, linking documents together,
annotating parts of them, and turning the result into a presentation.

It is a walkthrough rather than a reference. Each section links to the guide
page that covers the same ground in full, and to the concept page that explains
why Dash works that way.

## Before you start

The historical `browndash.com` deployment did not resolve when checked on
29 July 2026. Use the active deployment supplied by the Dash team or
[run the application locally](/getting-started/running-dash/).

If you have not seen the interface before, read
[the Dash workspace](/getting-started/environment/) first. It covers the
sidebar, the toolbar, and the dashboard and tab system that everything below
sits inside.

## Create a document

Four routes, all of which produce the same kind of object. Everything in Dash
is a document, including the collections that hold documents and the links
between them; [documents and fields](/concepts/documents/) explains what that
buys you.

**Start typing.** Click anywhere on a freeform canvas and type. You get a rich
text document.

![Screen recording: clicking on empty canvas and typing to create a text document.](/assets/gifs/gettingstarted/dash-create-text.gif)

**Drag and drop.** Drag a file from your computer or an image from a web page
onto the canvas. Images, video, audio, and PDFs are all accepted.

![Screen recording: dragging a file from the desktop onto a Dash canvas.](/assets/gifs/gettingstarted/dash-drag-drop.gif)

**Import.** Use the import menu in the left sidebar.

![Screen recording: importing files through the Dash import menu.](/assets/gifs/gettingstarted/dash-import.gif)

**Type a colon.** Typing `:` opens the document menu, which lists every
document type and is searchable. In stacking or schema view, click `+ New` and
then type a colon.

![Screen recording: typing a colon to open the document type menu and choosing a type.](/assets/gifs/gettingstarted/dash-colon-menu.gif)

The colon menu is the fastest way to reach the types that have no drag-and-drop
equivalent, which is most of the recent ones: data visualisations, 3D scenes,
video generators, equations, tasks.

### Nest a collection

A collection is a document, so a collection can contain collections. Create one
from the colon menu and add documents to it exactly as you would to the main
canvas, panning and zooming inside it.

![Screen recording: creating a nested collection and adding documents inside it.](/assets/gifs/gettingstarted/dash-nested-collection.gif)

You can also make a collection out of documents already on the canvas:
right-click and drag to marquee-select them, then create a collection from the
selection.

![Screen recording: marquee-selecting several documents and grouping them into a new collection.](/assets/gifs/gettingstarted/dash-create-collection-marquee.gif)

## Select documents

Left-click or right-click a single document to bring it into focus.

For multiple documents, right-click and drag on the canvas to draw a marquee
around them.

![Screen recording: drawing a marquee selection around several documents.](/assets/gifs/gettingstarted/dash-marquee.gif)

Or hold shift and left-click each one.

![Screen recording: shift-clicking to add documents to a selection.](/assets/gifs/gettingstarted/dash-shift-click.gif)

Inside a PDF or a web page, click and drag to select text rather than the
document.

![Screen recording: dragging across text inside a PDF to select it.](/assets/gifs/gettingstarted/dash-highlight-select.gif)

That distinction matters later: a selection is a valid link endpoint, so
selecting text inside a PDF and then linking gives you a link into the passage
rather than into the file.

## Edit and arrange

Three controls appear on any document, whatever its type.

**Document chrome** is the floating strip of tools on a selected document.

![Screenshot: the floating document chrome on a selected Dash document.](/assets/images/getting-started/document-chrome.png)

**The properties panel** on the right holds type-specific settings. Open it with
the double arrows in the top right, or the single arrow on the right edge of
the screen.

![Screen recording: opening the properties panel for a selected document.](/assets/gifs/gettingstarted/dash-properties-pane.gif)

**The context menu** opens on right-click, or from the three-bar menu at the
bottom of the document chrome.

![Screen recording: opening the right-click context menu on a document.](/assets/gifs/gettingstarted/dash-context-menu.gif)

There is also a context-sensitive toolbar whose contents change with the
document type.

![Screenshot: the context-sensitive toolbar, showing controls for the selected document type.](/assets/images/getting-started/context-toolbar.png)

To move a document, drag its title if it is selected, or hover and drag if it is
not. To resize it, drag the corner handles; the small circle in the bottom right
adjusts corner radius.

To close a document, use the leftmost "x" in the header chrome, or the trash
icon under the actions sub-panel, or "close" in the right-click menu. Closing is
not deleting. Closed documents stay in "My Recently Closed" in the files section
of the sidebar, and can be dragged back onto a canvas.

![Screen recording: reopening a document from the recently closed list in the sidebar.](/assets/gifs/gettingstarted/recently-closed.gif)

Links survive closing too. Following a link to a closed document reopens it in a
new tab.

### Open a document full-screen

Double-click a document, or click the green icon in the top right of its chrome,
to open it in lightbox view. The document behaves the same way there as it does
on the canvas.

![Screen recording: double-clicking a document to open it in full-screen lightbox view.](/assets/gifs/gettingstarted/dash-lightbox.gif)

## Change how a collection displays

A collection stores its layout as a property, so switching view converts
nothing and loses nothing. Change it from the dropdown at the left of the
context toolbar, or right-click the collection to open a second view of the
same contents as an alias.

The default is freeform. The others each suit a different question:
[freeform](/guides/views/freeform/) for spatial arrangement,
[schema](/guides/views/schema/) for a table you can sort and add columns to,
[stacking](/guides/views/stacking/) for a single scrollable column, and
[notetaking](/guides/views/notetaking/) for several columns side by side.

There are twenty-one view types in total, including calendar and a link graph.
[Collections and views](/guides/views/views/) covers the rest, and the
[collections concept page](/concepts/collections/) explains why layout is a
property rather than a conversion.

## Link two documents

A link in Dash is bidirectional, and the link itself is a document, so it can
carry a description, a relationship, and its own key-value fields. An anchor,
meaning the endpoint, can be a whole document or a selection inside one.

There are two ways to make one.

**Drag and drop** creates a single link between two documents that are both on
screen, whether in the same tab or in two tiles. Select the source, find the
link icon in its bottom toolbar, then drag that icon onto the destination.

Dash confirms the link and offers an optional label, which you can change later.
The source document then shows a count of its links.

![Screen recording: dragging the link icon from one document onto another to create a link.](/assets/gifs/gettingstarted/dash-creating-link.gif)

**The linkboard** works like a clipboard. It holds a source document until you
clear it, which is what you want when you are making several links from the same
source or linking while doing something else.

1. Select the source document and find the link icon in its bottom toolbar.
2. Left-click the icon. A bar appears at the bottom of the screen with controls
   for showing link labels and for leaving linking mode.
3. Click the target document, then the second link icon in the bottom menu.

![Screen recording: using the linkboard to create several links from one source document.](/assets/gifs/gettingstarted/dash-create-link-board.gif)

### Follow a link

A blue dot appears in the bottom left of a linked document, with the number of
links on it. Click the dot for the list; hover an entry to preview its
destination; click to follow.

By default, following pans the canvas until the destination is visible and
highlights it in orange.

![Screen recording: clicking a link indicator and following the link to its destination.](/assets/gifs/gettingstarted/dash-following-link.gif)

Turning on the pointing-hand icon makes a click anywhere on the document follow
its first link.

![Screen recording: toggling click-to-follow so clicking the document follows its first link.](/assets/gifs/gettingstarted/dash-follow-link-onclick.gif)

### Edit a link

Click the pencil icon beside a link in the list to open it in the properties
pane.

![Screen recording: opening a link in the properties pane from the link list.](/assets/gifs/gettingstarted/dash-edit-link.gif)

There you can set a relationship and description, show or hide the link line,
and change what following it does.

![Screen recording: editing a link's description and follow behaviour in the properties pane.](/assets/gifs/gettingstarted/dash-editing-link.gif)

The adjustment most people want first is zoom. By default following only pans
far enough to bring the destination into view; turning on **Zoom %** centres and
zooms into it instead, at a level you set.

![Screen recording: enabling zoom on link following so the destination is centred and enlarged.](/assets/gifs/gettingstarted/dash-link-center-zoom.gif)

Closing a document does not delete its links, and links can be removed from
either the link list or the properties pane.

[Links and anchors](/guides/features/linking/) is the full reference. The
[links concept page](/concepts/links/) explains why an anchor can be a region or
a timestamp rather than a file.

## Annotate part of a document

Media documents, meaning PDFs, web pages, images, video, and audio, accept
annotations. Several of the routes below create a link as a side effect, which
is how you end up linking to part of a document rather than all of it.

**From the annotation icon** in the top right of a document, which opens the
annotation sidebar.

![Screen recording: opening the annotation sidebar from the icon in a document's top right.](/assets/gifs/gettingstarted/dash-annotation-icon.gif)

**From a highlight.** Select text in a document, PDF, or web page and click the
annotation icon that appears. This links the annotation to the selection in both
directions: following it from the annotation scrolls the text into view, and
clicking the text scrolls the annotation into view.

![Screen recording: highlighting text and creating a linked annotation from the selection.](/assets/gifs/gettingstarted/dash-highlight-anno.gif)

**From a highlight, to an existing document.** After highlighting, click the
search icon to find a document to link the selection to.

![Screen recording: searching for a document to link a highlighted passage to.](/assets/gifs/gettingstarted/dash-search-anno.gif)

**From a marquee.** Left-click and drag inside an image, web page, PDF, or video
to select a rectangular region. On web pages and PDFs, click the annotation icon
to attach an annotation; on other media, drag the annotation icon somewhere else
to place it. Either way you get a link to that region.

![Screen recording: drawing a marquee over part of a PDF and annotating the region.](/assets/gifs/gettingstarted/dash-pdf-anno-marquee.gif)

![Screen recording: drawing a marquee over part of an image and annotating the region.](/assets/gifs/gettingstarted/dash-image-marquee-anno.gif)

**From a selection, to another document.** Make the selection, then drag the
link icon from the document's bottom toolbar onto the target. Because the
selection is still active, the link starts at the selection rather than at the
whole document.

![Screen recording: linking from a persistent selection to a separate document.](/assets/gifs/gettingstarted/dash-link-annotation-document.gif)

**On a timeline.** Drag across part of an audio or video timeline to annotate
that time range. Following a link into it plays that region.

![Screen recording: dragging across an audio timeline to annotate a time range.](/assets/gifs/gettingstarted/dash-audio-anno.gif)

**By typing on the document.** Text can be embedded directly onto images, PDFs,
web pages, and video.

![Screen recording: typing directly onto an image to embed a text annotation.](/assets/gifs/gettingstarted/dash-image-text-embed.gif)

**By drawing on it.** Ink strokes can be placed on any document.

![Screen recording: drawing ink strokes directly onto a document as an annotation.](/assets/gifs/gettingstarted/dash-annotation-ink.gif)

[Annotation and markup](/guides/features/markup/) covers the annotation types in
detail; [ink](/guides/features/ink/) covers drawing.

## Build a presentation trail

A trail is an ordered path through documents, closer to Prezi than to slides,
and you can step off it at any point to follow an ordinary link instead. Any
document can be pinned to one.

Create a trail from the trails panel in the left sidebar:

![Screen recording: creating a new presentation trail from the sidebar trails panel.](/assets/gifs/gettingstarted/dash-create-trail-side.gif)

Or by pinning a document, which creates the trail if none exists:

![Screen recording: pinning a document to a trail using the pin control in its decorations.](/assets/gifs/gettingstarted/dash-pin-doc.gif)

A new tab opens showing the trail's slides. Click a slide to move to it.

![Screen recording: clicking between slides in a trail and watching the canvas transition.](/assets/gifs/gettingstarted/dash-trail-transition.gif)

### Pin with a view

A regular pin captures the document. Pinning with a view captures the canvas at
a particular pan and zoom, which is how you show several documents laid out
together.

![Screenshot: a slide pinned to a trail without view properties.](/assets/images/trails/regularpin.png)

From the top menu bar, this pins the tab as you are currently looking at it:

![Screen recording: pinning the current canvas view to a trail from the top menu bar.](/assets/gifs/gettingstarted/dash-pin-with-view.gif)

From the marquee menu, which appears when you right-click and drag on the
canvas, the marquee bounds become the viewport:

![Screen recording: pinning a marquee region to a trail so its bounds become the slide viewport.](/assets/gifs/trails/pinmarqueeview.gif)

Hovering the pin icon exposes options for preserving layout and content.
Combined with grouping, which plays several slides together, this produces
transitions like the following:

![Screen recording: a trail transition where grouped slides animate their layout and content together.](/assets/gifs/gettingstarted/dash-pres-layout-content-grouping.gif)

The trails guide documents [the pinning options](/guides/features/trails/#other-pinning-options)
and [slide grouping](/guides/features/trails/#slides).

### Reorder and present

Drag slides to reorder them.

![Screen recording: dragging slides into a different order within a trail.](/assets/gifs/gettingstarted/dash-reorganize-slides.gif)

The double arrows in the trail tab open transition settings for each slide.

![Screen recording: adjusting a slide's transition settings in the trail customisation pane.](/assets/gifs/gettingstarted/dash-slide-editing.gif)

The stiffness, damping, and mass controls you see there are a spring model that
replaced the original mechanical transitions;
[presentation trails](/guides/features/trails/) records which cohort built it
and what else it changed.

Click present in the top right to enter presentation mode, then use the arrows
to move between slides or the play icon to advance automatically.

![Screen recording: presenting a trail full-screen and stepping through the slides.](/assets/gifs/gettingstarted/dash-present-trail.gif)

The dropdown also offers a mini-player, which keeps the canvas visible.

![Screen recording: playing a trail in the minimised mini-player.](/assets/gifs/gettingstarted/dash-pres-miniplayer.gif)

The [trails concept page](/concepts/trails/) explains where the idea comes from
and what Dash's version does not yet do.

## Share what you made

Documents can be shared with individuals, with groups, or both, at four levels
of access.

![Screen recording: sharing a dashboard with another user and setting their access level.](/assets/gifs/gettingstarted/sharing.gif)

[Collaboration](/guides/features/collaboration/) documents the permission levels
and how groups are created.

## If something goes wrong

The undo and redo controls in the bottom left of the canvas turn yellow while an
action is in progress. If they stay yellow, refreshing the browser is the
reliable fix.

Bugs go to the group through the reporting flow described in
[the Dash workspace](/getting-started/environment/#reporting-bugs).
