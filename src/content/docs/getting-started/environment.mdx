This page names the parts of the interface. It is worth reading once before
[your first session](/getting-started/using-dash/), because the rest of the
documentation assumes the vocabulary.

:::caution[Hosted service status]
Dash does not publish a guaranteed public hosted endpoint. Ask the Dash team
for the active deployment or [run Dash locally](/getting-started/running-dash/).
The screenshots document the current client interface, not the availability
of a particular deployment.
:::

## The home menu

Dash opens on a home menu for managing dashboards. You can view, delete, and
share your own dashboards here, and open ones other people have shared with you
under "Shared Dashboards". The "+ New Dashboard" button, or the empty dashboard
tile marked with a plus, creates a new one.

![The current Dash home menu showing a saved Trip Planner dashboard, shared dashboards, and the New Dashboard control.](/assets/images/current/dash-home-workspaces.webp)

A new dashboard opens on an empty freeform canvas: a pannable, zoomable,
unbounded 2D surface where most work happens. It is surrounded by the panels
described below.

![The current Dash interface showing the top bar, context toolbar, sidebar, tab strip, freeform canvas, embedded documents, map, and planner tool.](/assets/images/current/dash-trip-planner-workspace.webp)

Freeform is only the default. A collection stores its layout as a property, so
the same contents can be shown as a table, a calendar, or a link graph without
converting anything; see [collections and views](/concepts/collections/).

## The sidebar

The sidebar is pinned to the left. Each icon opens a flyout panel, toggled by
clicking the icon or the grey drag handle.

![Screen recording: opening and closing a sidebar flyout panel.](/assets/gifs/environment/dash-flyout.gif)

The current Files panel keeps personal dashboards, recently closed documents,
and folder creation beside the active canvas:

![The current Dash Files panel open beside a live trip-planning workspace.](/assets/images/current/dash-files-panel.webp)

| Icon | Panel | What it does |
| :--- | :---- | :----------- |
| ![](/assets/icons/search.png) | **Search** | Finds documents in the current dashboard by metadata. The dropdown filters by document type. Ctrl+F toggles it. |
| ![](/assets/icons/files.png) | **Files** | A file manager where you can group documents into folders independently of the dashboard. Also holds [recently closed](/getting-started/using-dash/#edit-and-arrange) documents. |
| ![](/assets/icons/tools.png) | **Tools** | An alternative route for creating certain document types, including maps, audio, and notes. |
| ![](/assets/icons/imports.png) | **Imports** | Where imported documents land. |
| ![](/assets/icons/shared.png) | **Shared** | Documents and dashboards other users have shared with you. To share something, right-click it and select `Share`. |
| ![](/assets/icons/trails.png) | **Trails** | Every presentation trail you have created. |

Global search matches text-valued document fields, including rich text when it
is stored in a searchable field. It does not crawl every byte of imported
files, live webpage DOM, or visual media. [Search](/guides/features/search/)
defines the exact scope and distinguishes it from the agent's semantic
retrieval.

The toolbar changes with what is selected. With the canvas selected it shows
view-level controls; with a document selected it shows controls for that
document type.

## Dashboards, tiles, and tabs

These three words are used precisely throughout the documentation, and they
nest: a dashboard holds tiles, a tile holds tabs, a tab holds a document.

### Dashboards

A dashboard is a particular layout of tiles and tabs. You can keep several, one
per workflow: a photo album in one, class notes in another. Documents can be
linked and moved between dashboards, but dashboards are meant to work
separately.

Create, share, and delete them from the home menu.

![Screen recording: creating, renaming, and deleting dashboards from the home menu.](/assets/gifs/environment/dash-managing.gif)

### Tabs

A tab works like a browser tab and can hold any Dash document.

Create one with the plus at the top right of a [tile](#tiles); close one with
the x on the tab itself.

![Screen recording: creating and deleting tabs in a tile.](/assets/gifs/environment/dash-create-delete-tab.gif)

To open a document in its own tab, drag the document's title bar onto the tab
manager and release. Clicking the darkened region that appears puts the new tab
in the current tile.

![Screen recording: dragging a document's title bar onto the tab manager to open it in a new tab.](/assets/gifs/environment/dash-drag-tab.gif)

To put it in a new tile instead, move the cursor to the part of the canvas where
you want the tile and click there rather than on the tab manager.

![Screen recording: dragging a document tab out to create a new tile beside the existing one.](/assets/gifs/environment/dash-drag-tab-tile.gif)

To merge a tab back, drag the document icon on the tab header into the target
tab.

![Screen recording: dragging a tab back into another tab to merge them.](/assets/gifs/environment/dash-drag-tab-back.gif)

### Tiles

A tile is a pane that holds one or more tabs, the way a browser window holds
tabs.

Create one by dragging the header of an existing tab to the part of the canvas
where you want it.

![Screen recording: dragging a tab header onto the canvas to create a new tile.](/assets/gifs/environment/dash-drag-tab-create-tile.gif)

Close one with the x at its top right.

![Screen recording: closing a tile with the x control at its top right.](/assets/gifs/environment/dash-close-tile.gif)

## Undo and redo

The arrows in the bottom left of the canvas undo and redo actions. Clicking the
stack lists past actions, and clicking one of those returns to it.

![Screenshot: the undo and redo controls in the bottom left of the canvas.](/assets/images/environment/undo-redo.png)

![Screen recording: undoing and redoing actions from the undo stack.](/assets/gifs/environment/undo-redo.gif)

The controls turn yellow while an action is in flight. If they stay yellow,
refresh the browser.

This is more load-bearing than it looks. Every mutation in Dash runs through a
single undo manager, and grouping changes into a named batch is what makes one
agent action revertible as a unit. [Architecture](/architecture/#undo-batches)
explains why that is also where action provenance had to attach.

## Reporting bugs

Dash is a research system under active development, so bugs are expected and
reports are useful. Click the bug icon in the top bar to see open issues and
file a new one. Feature suggestions go in the same place.

![Screen recording: filing a bug report from the top bar bug reporter.](/assets/gifs/environment/dash-report.gif)
