Dash is a visual knowledge workspace where a PDF, video, web page, recording,
rich-text note, dataset, task, map, 3D model, policy analysis, agent, and
collection are all addressable documents—and a link can start or end at a
precise region inside them.

It has been in continuous development since December 2018, almost entirely by
Brown undergraduates working in semester-length cohorts. This site documents
what Dash does, how it is built, and what each cohort contributed, with an
implementation status for every project that can be traced back to the code.

## Start here

If you are deciding whether Dash fits your work, open the
[capability catalog](/capabilities/). It is the implementation-verified product
inventory, with entry points, availability, technical references, and project
provenance.

If you are new to the interface, read [what Dash is](/overview/what-dash-is/),
then follow [Using Dash](/getting-started/using-dash/). If you have a concrete
goal, start with a [workflow](/workflows/).

If you want to judge the technical substance quickly, [System map](/architecture/system-map/)
traces the runtime and [current state](/overview/current-state/) records the
verified source snapshot. The [project index](/research/projects/) preserves all
forty recovered projects with evidence-backed status labels.

If you are about to work on Dash, [architecture](/architecture/) describes the
implementation and the four places you extend it.

## A note on how projects appear here

Projects are not the product navigation. Integrated projects map to canonical
capabilities, and capability pages link back to the historical evidence. The
graph project, for example, appears under
[Collections, views, maps, and data](/capabilities/organization/#graph-view);
its cohort write-up remains the record of who built it and what happened.

The [project index](/research/projects/) is the provenance map, not the feature
manual.

:::caution
Dash is a research system under active development by students, not a product.
Expect rough edges, and expect the interface in older screenshots on this site
to differ from what you see. Where a page describes something no longer in
Dash, it is marked rather than deleted.
:::
